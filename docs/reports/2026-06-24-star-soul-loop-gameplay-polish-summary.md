# 星魂回环玩法打磨阶段总结

## 已完成

- 编辑器玩家术语统一为核心、连接件、功能模块、软硬件、推进器，同时保留旧内部键。
- 伤害严格执行 `动量 * 伤害系数 * 调整系数`，伤害等于破防值时阻断，阻断仍可击退。
- 斩击 `1.5x` 伤害、刺击 `0.5x` 破防门槛、钝击 `2x` 击退已由独立探针覆盖。
- 电能/激光与化学投射物固定动量为 `1`，显式质量或动量数据不能覆盖。
- 单位编辑合法性规则已逐项映射到现有门禁或明确的后续服务与探针。
- 硬件故障、损毁、核心销毁、存档兼容、确定性回放、诊断/战报提示和故障部件战斗内视觉标记已形成实现闭环。
- Source Code 优先级纯数据服务已实现，支持排序、移动、存活载体过滤和傀儡组存档往返。
- 战斗诊断已增加 `raw_momentum`、`capped_momentum`、`break_gate`、`final_damage` 和 `knock_momentum`。
- 代表性平衡数值记录在 `docs/reports/2026-06-24-star-soul-loop-balance-examples.md`。

## 后续实现

- 精确插槽尺寸、单构件体单厂商、角色必需软件的硬合法性门槛。
- 硬件 `normal -> faulted -> destroyed` 战斗运行时。
- Source Code 优先级编辑 UI 与构件体分配运行时。
- PVE 剧情、PVE 肉鸽和玩家档案系统。
- 现有爆炸投射物预处理与爆炸伤害入口之间的契约冲突。

## 兼容策略

本阶段不迁移旧存档拓扑键。`torso`、`limb_muscle`、`muscle`、`joint`、`booster`、`tear`、`pierce` 和投射物路径中的 `laser` 继续作为内部兼容 ID；新术语优先用于玩家界面、文档和诊断。
