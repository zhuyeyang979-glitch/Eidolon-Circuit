# 星魂回环平衡诊断样例

## 诊断字段

详细数值只进入战斗诊断与赛后记录，不增加常驻 HUD 信息。

| 字段 | 含义 |
| --- | --- |
| `raw_momentum` | 接触或投射物进入限制前的原始动量 |
| `capped_momentum` | 路径刚度或后续硬件承载规则限制后的结算动量 |
| `damage_coefficient` | 武器或接触伤害系数 |
| `adjustment_coefficient` | 动作、材料、易伤等合并后的伤害调整系数 |
| `break_value` | 目标基础破防值 |
| `break_gate` | 调整后的实际破防门槛，等于 `effective_break_value` |
| `final_damage` | 门槛、材料、连段和持续伤害前置分配后的即时伤害 |
| `knock_momentum` | 本次用于击退或拉近的动量 |

## 固定样例

| 场景 | 输入 | 结果 |
| --- | --- | --- |
| 低动量 | 动量 2，伤害系数 1，调整系数 1，破防值 3 | 伤害值 2，小于门槛 3，阻断 |
| 等值破防 | 动量 10，伤害系数 2，调整系数 1，破防值 20 | 伤害值 20 等于门槛，仍然阻断 |
| 斩击 | 动量 10，伤害系数 1，斩击调整 1.5，破防值 14 | 伤害值 15，大于门槛，通过 |
| 刺击 | 动量 10，伤害系数 1，基础破防值 18，刺击门槛调整 0.5 | 实际 `break_gate` 为 9，伤害值 10，通过 |
| 钝击 | 动量 12，伤害值 12，破防值 20，击退调整 2 | 伤害阻断，但 `knock_momentum` 为 24 |
| 电能投射物 | 数据写入动量 999、质量 999 | 固定动量仍为 1 |
| 化学投射物 | 数据写入动量 999、质量 999；基础伤害 10，前置 0.25，DoT 系数 1.2 | 固定动量 1，即时伤害 3，持续伤害总量 12 |

## 运行时接触基准

`tools/momentum_damage_gate_runtime_probe.gd` 使用原始接触动量 80 和攻击路径上限 60：

- `raw_momentum = 80`
- `capped_momentum = 60`
- `damage_coefficient = 2`
- `adjustment_coefficient = 0.09`
- 结算伤害浮点值 10.8，最终即时伤害 11
- `break_gate = 0.5`
- `knock_momentum = 60`

这组数据用于确认诊断链路，而不是最终平衡目标。以后调整系数时，应同步修改样例探针和本说明，并在变更记录中写明原因。
