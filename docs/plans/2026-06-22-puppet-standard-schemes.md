# Puppet Standard Schemes / 傀儡标准方案

这些方案是给玩家的参考起点，不是新的合法性限制。玩家可以直接照着做，也可以替换 Source Code、武器、引擎、散热、行动模块、成员数量，或者把方案拆成自己的保存傀儡组。

当前构筑语境：

- 队伍总预算按英雄、傀儡、结界、备用单位一起计算。
- 普通 Source Code 傀儡组会被限制在 `1..11` 个身体。
- 保存傀儡组至少需要 `2` 个合法傀儡成员；设计上建议也控制在 `11` 个以内。
- 每边战场上同时只有一个主傀儡组在线。

## 美工优化目标 / Visual Identity Pass

这次优化只解决一个问题：玩家在截图或战场上远看时，至少能把七套参考傀儡区分开。它不增加新的规则，也不禁止玩家替换零件。

执行标准：

- 先看轮廓：每套方案要有不同的核心体型或外形宽窄。
- 再看主武器：盾、枪、细剑、喷射器、激光、浮游小枪要能形成不同剪影。
- 再看数量和站位：少量精锐、横向屏障、密集无人机群必须一眼不同。
- 最后看材质/颜色倾向：护卫偏冷色硬边，热压偏红橙，浮游云偏小而亮，廉价组偏简单低饱和。

建议的展示部件基准：

| 方案 | 远看轮廓 | 主视觉部件 | 不应看起来像 |
| --- | --- | --- | --- |
| Guard Starter | 小到中型护卫，盾面/拳套在前 | `BUCKLER RAM SHIELD`、`AURORA BASH SHIELD`、短刺 | 远程枪队 |
| Ranged Pack | 轻核心加细长枪线 | `LIGHT RIFLE MUSCLE`、`LONGSIGHT PRISM LASER`、化学喷射器 | 近战包夹 |
| Pincer Pair | 窄身、高速、长刺/刀尖明显 | `HUMANOVA DUEL CORE`、`HUMANOVA NEEDLE RAPIER`、`TRAINING FOIL RAPIER` | 横向盾墙 |
| Screen Wall | 宽、厚、横向阻挡感 | `CRAB TORSO CHASSIS`、`AURORA BASH SHIELD`、重连接件 | 无人机群 |
| Thermal Pit Crew | 多种热武器混编，红橙热压感 | 激光、化学喷射器、轻枪、冷却/支援节点 | 普通步枪队 |
| Drone Cloud | 极小核心、数量多、单体很脆 | `FLOATING BIT CORE`、轻枪 | 中型机体小队 |
| Cheap First Entry | 简单、低成本、少装甲 | `FLOATING BIT CORE`、轻枪、训练细剑/短刺 | 精锐护卫或重盾墙 |

验收方式：同一张战场总览图里，七套参考方案不能只靠标题区分；遮住标题后，也应能从数量、体型、主武器轮廓看出大致职责。

## 1. 护卫入门组 / Guard Starter

目标：保护英雄，适合第一次使用傀儡的玩家。

- 推荐 Source Code：`CODE: GUARD ORBIT` 或 `CODE: BODYGUARD SCREEN`
- 推荐数量：`3` 个
- 参考预算：`280-420`
- 身体方向：小型核心，尽量轻，不要做成长肢体巨型单位
- 武器方向：拳套、盾击、短刺、短刀，优先稳定接触
- 行动模块：优先 armor/拦截类；可加 `PUPPET ROUTINE: THREAT MEMORY`
- 战斗效果：围着英雄转，敌人靠近时先拦截，不追太远

可以怎么改：

- 想更硬：换更高 HP 的关节和近战武器，但会吃预算。
- 想更灵活：降低武器重量，给每个成员更好的引擎/推进器。
- 想保护傀儡自己：把 Source Code 改成 `VANGUARD COVER B`。

## 2. 远程点名组 / Ranged Pack

目标：用枪线、激光、化学武器持续压制敌方英雄。

- 推荐 Source Code：`CODE: RANGER PACK A`
- 推荐数量：`3` 个
- 参考预算：`360-560`
- 身体方向：轻型核心或浮游核心，保持短长度
- 武器方向：步枪、激光、化学喷射器；每个成员至少保留弹药/散热空间
- 行动模块：优先 ranged/manual/auto aim 相关模块
- 战斗效果：保持距离，优先敌方英雄和低血量目标，敌人贴近时 kite

可以怎么改：

- 想打爆发：把一名成员换成导弹/榴弹，但预算会上升。
- 想打消耗：多放化学或激光，强化散热和弹药。
- 想更保守：换 `CODE: SIEGE BATTERY`，数量少但站位更远。

## 3. 双路包夹组 / Pincer Pair

目标：用上下路夹击制造命中窗口，配合近战英雄压迫。

- 推荐 Source Code：`CODE: PINCER` 或 `CODE: DUEL TEMPO`
- 推荐数量：`2` 个，进阶可做 `3` 个
- 参考预算：`260-430`
- 身体方向：轻到中型，速度优先
- 武器方向：长刺、镰刀、刀、短冲刺武器
- 行动模块：normal + active 轮换，适合 whiff punish
- 战斗效果：两名傀儡分高低线，从不同 lane 合围目标

可以怎么改：

- 想更杀伤：提高武器质量和 active 模块质量。
- 想更便宜：只做两个非常轻的刺击傀儡。
- 想更扰乱：加入 `PUPPET ROUTINE: PACK FLANK`，避免全部挤在同一条线。

## 4. 屏障线组 / Screen Wall

目标：在敌方英雄和己方英雄之间形成移动屏障。

- 推荐 Source Code：`CODE: SCREEN WALL` 或 `CODE: BODYGUARD SCREEN`
- 推荐数量：`3-4` 个
- 参考预算：`380-650`
- 身体方向：中等 HP，宽度和抗性比速度更重要
- 武器方向：盾击、钝击、短程拦截武器
- 行动模块：armor 优先，normal 补伤害
- 战斗效果：站在双方之间，吸收接近路线，帮英雄获得安全输出或散热时间

可以怎么改：

- 想搭配结界：用 `CODE: FOLD STAGE CREW`，朝傀儡/结界转换方向发展。
- 想便宜：减少到 3 个，降低武器质量，保留 armor 逻辑。
- 想抗射击：提高电子护甲或抗弹材料比例。

## 5. 热压轮换组 / Thermal Pit Crew

目标：围绕热量系统打节奏，压迫高热或过热目标。

- 推荐 Source Code：`CODE: THERMAL PIT CREW`
- 推荐数量：`4` 个
- 参考预算：`480-720`
- 身体方向：中小型，散热要够，避免自己先过热
- 武器方向：激光、化学、轻枪，搭配一部分拦截武器
- 行动模块：armor 覆盖 + ranged pressure；可以混入主动散热模块
- 战斗效果：优先高热/过热目标，形成持续压力，而不是一次性秒杀

可以怎么改：

- 想更凶：增加激光和导弹，但要补散热。
- 想更稳：降低武器热量，放更多冷却和护卫模块。
- 想配合英雄：英雄使用爆发构筑，傀儡负责逼迫敌人进入高热状态。

## 6. 浮游云组 / Drone Cloud

目标：用大量小型傀儡制造空间噪音和火力覆盖。

- 推荐 Source Code：`CODE: DRONE CLOUD`
- 推荐数量：`8-10` 个
- 参考预算：`420-780`
- 身体方向：`FLOATING BIT CORE` 这类极小核心
- 武器方向：每个身体只装一件轻武器或轻模块，不要堆重件
- 行动模块：简单 normal 序列即可
- 战斗效果：数量多、体积小、便宜，但单个成员很脆

可以怎么改：

- 想更便宜：减少到 6-8 个，降低武器质量。
- 想更强：提高个别核心的枪械质量，而不是每个都加重。
- 想更可控：改成 `CODE: SYNTAX XI`，数量上限更高但更偏阵型纪律。

## 7. 廉价首发组 / Cheap First Entry

目标：让傀儡可以作为早期出场选项，不挤占太多英雄预算。

- 推荐 Source Code：`CODE: LINE` 或 `CODE: VAULT SENTRIES`
- 推荐数量：`2-3` 个
- 参考预算：`160-260`
- 身体方向：最小合法身体，少装重武器
- 武器方向：短刺、轻枪、低成本钝击
- 行动模块：一个简单模块即可，不追求复杂连段
- 战斗效果：早部署、占位、试探、拖时间

可以怎么改：

- 想抢首发：把 deploy cost 压到首发上限以内。
- 想中期更有用：提高 Source Code 或武器，但会失去廉价首发定位。
- 想配合主英雄：只保留干扰和拦截，让预算给英雄核心构筑。

## 使用原则

标准方案只回答“我该从哪里开始”。最终构筑仍由玩家决定。

- 不因为使用标准方案获得隐藏加成。
- 不因为偏离标准方案受到惩罚。
- 不限制玩家替换 Source Code、武器、模块或成员。
- 训练报告和战后复盘只解释表现，不强制玩家改回标准方案。
- 如果保存傀儡组数量超过普通 Source Code 的 `11` 个上限，应该提示这是高级/待平衡玩法，而不是默认推荐。
